PASS — Email-only Customer OTP architecture.

PASS — Customer bearer tokens cannot authorize Admin, Super Admin, Partner or Coordinator roles.

PASS — Access and refresh tokens are stored as hashes server-side.

PASS — Access token lifetime: 30 minutes.

PASS — Refresh token lifetime: 30 days and rotates on refresh.

PASS — Logout revokes the server-side mobile session.

PASS — Customer OTP rate limits and 10-minute expiry are present.

PASS — Public OTP request does not reveal privileged account existence.

PASS — New Customer creation requires a recent verified OTP challenge and explicit Terms/Privacy consent.

PASS — Customer request detail/repeat queries are customer-owned.

PASS — Family-member lookup is customer-owned.
